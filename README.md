## What you need

- An **n8n instance** (n8n Cloud, or self-hosted — the templates run on the free/self-hosted tier)
- A **Google account** (Sheets, Gmail and Drive do the heavy lifting in most templates — no paid CRM needed)
- Templates **2, 8, 10, 11, 13, 14, 17 and 18**: an **OpenAI API key** (pay-as-you-go; the AI steps cost a fraction of a cent per run)
- Template **7** only: access to the **WhatsApp Business Platform** — Meta's Cloud API directly, or a provider (Twilio, 360dialog, WATI…) which charges per conversation
- Template **10** only: a **vector database** account (a Supabase free tier is enough) — this is the one Advanced build in the pack

Every credential in these files is a **placeholder**. On import, n8n will ask you to connect your own accounts — nothing here can see, store or send your data anywhere except where you point it.

## How to import (same for all eighteen)

1. In n8n, open **Workflows → ⋯ → Import from File** and pick the template's `workflow.json`.
2. Open the workflow and follow its sticky notes top to bottom.
3. Connect your Google (and, where listed, OpenAI) credentials where the nodes ask for them, and replace the placeholder values (sheet ID, folder ID, your email address, feed URL) — each template's README lists exactly where they are.
4. Run the built-in test described in the README, check the result, then flip the workflow to **Active**.
